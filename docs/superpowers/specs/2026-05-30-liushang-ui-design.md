# 流觞 UI 设计 Spec

## 概述

「流觞」移动端 Web UI 设计，水墨纸笺视觉基调，单 HTML 原型先行，验证后转 React + Vite 工程。

## 开发策略

两步走：
1. **第一步**：用 build-frontend skill 生成单文件 HTML 原型，Vue/React CDN 驱动，验证视觉和交互
2. **第二步**：确认视觉后，将原型转成 React + Vite 正规工程

原型阶段视频用静态占位图（渐变色 + 标题水印），聚焦卡片体验。

## 页面范围

单页应用，底部 Tab 切换：视频流 / 上游 / 我的。流觞卡从视频流内浮现。

四个页面：
1. 视频流首页
2. 流觞卡组件（核心）
3. 上游封存页
4. 我的页面

额外：可切换的调试面板。

---

## 设计基础

### 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-void` | `#0a0a0f` | 视频区域最深背景 |
| `--bg-deep` | `#141419` | 页面底色 |
| `--card-paper` | `rgba(245,240,230,0.12)` | 纸笺卡片背景（半透明，视频流内用） |
| `--card-paper-solid` | `#f5f0e6` | 纸笺不透明版本（上游/我的页用） |
| `--ink-primary` | `#e8e0d0` | 主文字（泛黄墨色） |
| `--ink-secondary` | `rgba(232,224,208,0.6)` | 次要文字 |
| `--accent-water` | `#5a9e8f` | 青绿水痕强调 |
| `--accent-gold` | `#c9a96e` | 暖金点缀（标签、来源行） |
| `--accent-glow` | `rgba(90,158,143,0.15)` | 水痕光晕 |

### 字体

- **回响句**：`"Noto Serif SC", "Songti SC", Georgia, serif`，`18-20px`，行高 `1.8`，居中
- **UI 文字**：`-apple-system, "PingFang SC", sans-serif`
- **调试面板**：等宽字体 `12px`

### 动效原则

- 卡片浮现：`translateY(100%) → translateY(0)`，`opacity 0→1`，`800ms` ease-out
- 卡片消失：`translateY(0) → translateY(100%)`，`opacity 1→0`，`600ms` ease-in
- 页面切换：淡入淡出 `300ms`
- 收下反馈：`scale(1) → scale(0.95) → scale(1)` 短暂收缩后漂走
- 水痕光晕：`opacity 0.1↔0.2` 脉动，周期 `4s`

### 视口基准

移动端优先，`390px` 宽度基准。桌面端居中展示，最大宽度 `430px`，两侧留黑边。

## 页面一：视频流首页

### 布局

```
┌─────────────────────────┐
│  推荐 / 关注 / 流觞      │ 顶部导航，半透明底
│                    [🐛]  │ 调试开关
│                         │
│    [静态占位图]           │ 全屏视频区
│    主题色渐变 +           │
│    视频标题水印            │
│                         │
│              ♥ 12.3w    │ 右侧操作栏
│              💬 842     │
│              ⭐ 收藏     │
│              ↗ 分享     │
│                         │
│  @海边的古典课            │ 底部信息
│  为什么奥德修斯的归途...   │
│  #归乡 #远行 #久别        │ 主题标签
│                         │
│  [视频流] [上游] [我的]   │ 底部 Tab
└─────────────────────────┘
```

### 占位图方案

不用纯色块。每个主题配不同渐变：
- 归乡：深蓝 → 暗紫
- 城市：深灰 → 暖橙
- 疲惫：暗绿 → 深蓝
- 旧友：暗棕 → 深灰
- 成长：暗青 → 深紫

渐变上叠加视频标题作为水印，`--ink-secondary` 色 `30%` 透明度。

### 右侧操作栏

- 图标用线性 SVG，颜色 `--ink-secondary`，hover/active 变 `--ink-primary`
- 竖向排列，距右 `16px`，垂直居中偏下
- 包含：点赞、评论、收藏、分享

### 底部信息区

- 作者名 `14px` `--ink-primary`
- 标题 `13px` `--ink-secondary` 最多两行截断
- 主题标签用 `--accent-water` 小药丸，横向排列

### 视频切换

上滑切换下一个视频，`touch` 事件监听，`translateY` 动画 `400ms`。

### 顶部导航

- 半透明底色 `rgba(10,10,15,0.6)` + `backdrop-filter: blur(8px)`
- "流觞" tab 点击时，右上角显示水滴计数器（已收下几张）

### 调试面板

右上角开关切换，半透明黑底浮层，贴在视频右侧：
- 当前标签 `["归乡","久别"]`
- 停留秒数 `23s`
- 触发置信度 `0.78`
- 累计同类视频 `3`
- 等宽字体 `12px`，`--accent-water` 色

## 页面二：流觞卡组件

这是整个产品最关键的 UI。

### 触发与浮现

分两个阶段：

**阶段 1（0-400ms）**：底部水痕光晕出现
- 视频底部出现 `--accent-glow` 脉动光晕
- 右侧操作栏开始淡出

**阶段 2（400-1200ms）**：卡片从底部漂入
- 视频区上移压缩，亮度降低（`filter: brightness(0.5)`）
- 卡片从屏幕底部向上漂入

### 卡片结构

宽度 `calc(100% - 48px)`，水平居中，最大高度 `60vh`：

```
┌───────────────────────────┐
│                           │
│  上游来信                  │ 标题 14px --accent-gold
│  你在这条河边停了一会儿。   │ 副标题 12px --ink-secondary
│                           │
│  "所谓回家，不一定是回到    │ 回响句 20px 衬线 居中
│   一个地方。"              │ --ink-primary 行高1.8
│                           │
│  来自 127 天前的一次停留    │ 来源 11px --accent-gold
│                           │
│  [收下] [留一句] [继续刷]   │ 动作按钮
│                           │
└───────────────────────────┘
```

背景：`--card-paper`（`rgba(245,240,230,0.12)`），`backdrop-filter: blur(20px)`，圆角 `16px`。

### 动作按钮

| 按钮 | 样式 | 行为 |
|------|------|------|
| 收下 | `--accent-water` 实底，白字，圆角 `8px` | 卡片收起，底部飘出"已收下"提示 `2s` |
| 留一句 | 透明底 + `--accent-water` 描边，圆角 `8px` | 展开输入区 |
| 继续刷 | 纯文字 `--ink-secondary`，最小视觉权重 | 卡片向下漂走消失 |

### 留一句输入区

点击"留一句"后卡片内展开：
- `max-height` 动画 `400ms`
- textarea 最多 60 字
- placeholder："给后来刷到这里的人留一句..."
- 实时字数计数器，接近上限时变 `--accent-gold`
- 提交按钮："放下这句"，`--accent-water` 实底
- 提交后卡片关闭，飘出提示"这句话会漂向后来者"

## 页面三：上游封存页

### 风格切换

从视频流深色切换到浅色纸笺底 `--card-paper-solid`（`#f5f0e6`），有"翻开册子"的转场感。转场用 `rotateY` 动画 `600ms`。

### 布局

```
┌─────────────────────────┐
│  ← 返回    上游          │ 顶部导航
│                         │
│  ┌───────────────────┐  │
│  │  2026 春          │  年份季节 12px --ink-secondary
│  │  关于归乡的流觞     │  档案名 22px 衬线 --ink-primary
│  │  ───── 水痕线 ─── │  --accent-water 横线
│  │  这一轮流觞里...   │  AI 短序 14px 斜体 行高1.8
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │  "回响句内容"      │  回响卡片，左侧 3px --accent-water 竖线
│  │   来自 127 天前    │  16px 衬线
│  └───────────────────┘  │
│                         │
│  （更多回响卡片...）      │
│                         │
│  #久别  #远行  #释然     │ 关键标签 --accent-gold 药丸，可横向滚动
│                         │
│  ┌───────────────────┐  │
│  │  已封存 · 共 42 条 │  封存状态徽章 --card-paper-solid 底色
│  └───────────────────┘  │
│                         │
│  [视频流] [上游] [我的]   │
└─────────────────────────┘
```

### 关键细节

- 回响卡片：左侧 `3px` 宽 `--accent-water` 竖线，像书页边注
- 主题标签横向排列，点击可切换到其他主题封存页（归乡→旧友→疲惫→成长→城市）
- 封存徽章固定在底部标签栏上方

## 页面四：我的页面

### 风格

延续上游页浅色纸笺底 `--card-paper-solid`。

### 布局

```
┌─────────────────────────┐
│  ← 返回    我的          │ 顶部导航
│                         │
│  漂过的河                │ 小标题 14px --ink-secondary
│  归乡 · 3次  旧友 · 1次  │ 参与过的主题，点击跳转上游页
│  疲惫 · 2次              │
│                         │
│  我收下的话              │ 分区标题 16px 衬线
│  ───── 水痕线 ───       │
│                         │
│  ┌───────────────────┐  │
│  │  "回响句"          │  --accent-water 左竖线
│  │         3天前收下   │  收下时间 11px --ink-secondary
│  └───────────────────┘  │
│                         │
│  我留过的话              │ 分区标题 16px 衬线
│  ───── 水痕线 ───       │
│                         │
│  ┌───────────────────┐  │
│  │  "我留的话"        │  --accent-gold 左竖线（区别于收下）
│  │    已被 7 人收到    │  被后来者收到次数
│  └───────────────────┘  │
│                         │
│  [视频流] [上游] [我的]   │
└─────────────────────────┘
```

### 关键细节

- 收下的回响用 `--accent-water` 左竖线，我留的用 `--accent-gold` 左竖线
- "已被 X 人收到"是关键反馈闭环
- 空状态显示轻引导文案而非空白（"下次收到流觞卡时，可以留一句给后来者"）

## 底部 Tab 栏

所有页面共享：
- 三个 tab：视频流 / 上游 / 我的
- 半透明底 `rgba(10,10,15,0.8)` + `backdrop-filter: blur(12px)`
- 当前 tab 用 `--accent-water` 高亮
- 视频 tab 带水滴计数器角标（收下数量）

---

## 交互全局规则

- 所有页面切换用淡入淡出 `300ms`，上下游页进入加 `rotateY` 翻页感
- 触摸手势：视频流上滑切视频，卡片内下滑关闭
- 无 loading 态（预设数据，瞬间渲染）
- 无 404/错误态（原型阶段不处理）
